 # 📊 Telecom Customer Churn Analysis & Prediction

> End-to-End Data Analytics & Machine Learning Project using **SQL, Python, Scikit-learn, and Power BI**


# 📖 Project Overview

Customer churn is one of the biggest challenges faced by telecom companies. Losing existing customers directly impacts revenue and profitability.

This project analyzes historical customer behavior, identifies the key reasons behind churn, builds a machine learning model to predict future churn, and visualizes business insights using interactive Power BI dashboards.

The project follows a complete analytics workflow:

- Data Cleaning
- SQL Analysis
- Exploratory Data Analysis
- Feature Engineering
- Machine Learning
- Model Optimization
- Customer Churn Prediction
- Interactive Power BI Dashboard
- Business Recommendations

---

# 🎯 Business Problem

The telecom company wants to answer the following questions:

- Why are customers leaving?
- Which customers are likely to churn?
- How much revenue is at risk?
- Which customer segments require immediate attention?
- What actions should the retention team take?

# 📌 Key Business Insights

### Historical Insights

- Competitor offers are the leading cause of customer churn.
- Customers with Month-to-Month contracts have significantly higher churn.
- Customers paying higher monthly charges churn more frequently.
- Most churn occurs during the first year of service.

### Predictive Insights

- High-risk customers are primarily on Month-to-Month contracts.
- Fiber Optic users represent the majority of predicted churners.
- Bank Withdrawal customers have the highest predicted churn concentration.
